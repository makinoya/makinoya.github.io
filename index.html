多 Agent 实时交易

决定“这一瞬间，电力应该怎么流”

家庭能源系统中存在多种可能的能量流向，光伏直供负荷、光伏为储能充电、储能向负荷供电、储能向电网馈电、以及电网为储能充电等。调度不仅要决定“往哪里流”，还要决定“流多少”。传统状态机或规则式调度通常需要预先定义能量流模式及切换条件，面对不同结构的家庭系统容易变得复杂、僵硬。

我们不预设运行模式，而是将负载、光伏、储能和电网抽象为独立 Agent，让它们在交易市场上自主协调当前时刻的能量流向和功率大小。各 Agent 根据自身状态进行报量报价，形成买单和卖单；交易系统以分钟级的高频周期撮合买卖单，最终根据各 Agent 的成交量确定本周期的供电与用电功率。

这种机制具有天然的实时响应能力：当负荷、光伏出力或电价发生跳变时，下一轮报价与撮合会立即重新分配能量流向和流量，“涌现”出适合当前状态的改变。

02 /

储能 SOC 的边际价值报价

决定“电力应该如何跨越时间提高价值”

储能具有跨时间搬运电力的能力。为了让储能 Agent 理解如何在不同时间之间调配电力，我们为其建立 SOC 边际价值。

在其他条件相同的情况下，SOC 越高，继续充电的边际价值越低、放电意愿越强；SOC 越低，剩余电量越珍贵，继续放电的意愿越弱、充电意愿越强。我们结合未来电价、光伏与负荷的概率分布或场景分布，使用动态规划方法将这种直觉转化为可计算的数值，并进一步考虑充放电效率和电池折旧等物理约束，将这些信息翻译为“电池 Agent 在当前时间点愿意以什么价格充入一单位电、又愿意以什么价格释放一单位电”。

配合动态电价的 15 分钟变化周期，重新计算最新的边际价值曲线，并考虑充放电功率形成订单。最终，拍卖机制将订单与光伏、负载和电网的订单放入同一个市场中撮合，从而形成能追求未来机会价值的当前充放电指令。

两套机制 · 一个闭环

让当前行动，带着对未来的判断。

SOC 边际价值模型 · 利用未来信息

“这一单位电未来值多少钱？”

实时拍卖机制 · 利用当前负载、光伏、电价

“这一刻电应该往哪里流、流多少？”

两套机制分别解决不同时间尺度的问题。因此，系统无需预先写死“光伏优先充电”“高价时必须放电”等固定运行模式，而是持续经历：

  1. 状态感知
  2. 未来价值评估
  3. Agent 报价
  4. 市场撮合
  5. 执行

形成一个能够随不同家庭特征和外部环境持续自适应调整的智能管理闭环。
