通过实时交易协调当前供需，通过储能边际价值评估未来机会，

核心功能 01 /

多 Agent 实时交易

决定“这一瞬间，电力应该怎么流”

家庭能源系统中存在多种可能的能量流向，光伏直供负荷、光伏为储能充电、储能向负荷供电、储能向电网馈电、以及电网为储能充电等。调度不仅要决定“往哪里流”，还要决定“流多少”。传统状态机或规则式调度通常需要预先定义能量流模式及切换条件，面对不同设备组合和运行状态时容易变得复杂、僵硬。

我们不预设运行模式，而是将负载、光伏、储能和电网抽象为独立 Agent，让它们在交易市场上自主协调当前时刻的能量流向和功率大小。各 Agent 根据自身状态和价值判断进行报量报价，形成买单和卖单；交易系统以分钟级周期撮合买卖单，最终根据各 Agent 的净成交量形成当前能量流分配，并转化为储能的充放电功率指令。

这种机制具有天然的实时响应能力：当负荷、光伏出力或电价发生跳变时，下一轮报价与撮合会立即重新分配能量流向和流量，“涌现”出适合当前状态的改变。

交互示意展示了“报价 → 撮合 → 能量流重组”的完整过程。切换负荷、光伏或电价场景后，各 Agent 的订单与成交结果随之变化，能量流即时重新组织。

核心功能 02 /

储能边际价值报价

决定“电力应该如何跨越时间提高价值”

储能具有跨时间搬运电力的能力。如果仅因为当前电价较高就立即放电，虽然能够获得当期收益，却可能损失覆盖未来更高电价时段的机会。合理的充放电决策需要同时比较当前动作的即时收益，以及当前电量或剩余容量在未来可能产生的机会价值。

为了让储能 Agent 能够同时考虑当前收益与未来机会，我们为其 SOC（State of Charge）建立了边际价值模型。

在其他条件相同的情况下，SOC 越高，继续充电的边际价值越低、放电意愿越强；SOC 越低，剩余电量越珍贵，继续放电的意愿越弱、充电意愿越强。我们结合未来电价、光伏与负荷的不确定性场景，使用动态规划方法将这种直觉转化为可计算的数值，并进一步考虑充放电效率和电池折旧等物理约束，将这些信息翻译为“电池 Agent 在当前时间点愿意以什么价格充入一单位电、又愿意以什么价格释放一单位电”。

将当前收益与未来机会统一为同一套边际价值，使电池能够比较“现在行动”与“保留机会”之间的得失。再与负载、光伏和电网的报价共同进入市场，决定当前是否充电、放电以及对应功率。

交互示意展示了系统如何将未来信息回溯为当前的储能边际价值。当未来光伏出力、负荷场景或电价分布发生变化时，当前充电与放电的机会价值也会随之调整；在进一步考虑充放电效率和电池折旧后，Battery Agent 将据此生成相应的买入与卖出报价。

两套机制 · 一个闭环

让当前行动，带着对未来的判断。

SOC 边际价值模型 · 利用未来信息

“这一单位电未来值多少钱？”

实时拍卖机制 · 利用当前负载、光伏、电价

“这一刻电应该往哪里流、流多少？”

两套机制分别解决不同时间尺度的问题：边际价值报价把“未来”压缩成当前价格，多 Agent 交易用当前价格组织“现在”的能量流。系统由此形成闭环：

  1. 状态感知
  2. 未来价值评估
  3. Agent 报价
  4. 市场撮合
  5. 执行

执行后进入下一周期重新评估，持续更新未来价值与当前行动。
